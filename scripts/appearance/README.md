# Visitor appearance picker

Header Theme button beside the existing Dark mode control. Six palettes (Coral, Ocean, Forest, Violet, Amber, Graphite) and a custom accent via native color input or hex code. Palette and light/dark preferences remain independent and are saved in separate localStorage keys. Existing visitors retain their mode; Coral remains the default. Palette tokens apply in the document head before CSS loads. Invalid saved preferences revert safely to Coral; storage failures show an honest unsaved-preview message. Changes in other tabs update the palette through the storage event.

The nonmodal dialog uses native radio controls with arrow-key selection, Escape restores focus to Theme, and outside click or focus departure closes it. Small viewports use a scrollable panel within the screen edges. Main application colors follow shared tokens; circuit semantic voltage/current colors retain their meanings while its surfaces follow the selected palette.
